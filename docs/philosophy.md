# Philosophy

Meta Harness treats coding-agent work as an evidence-gated control plane.

The parent agent should not advance because a worker sounds confident. It advances when the phase manifest, slice plan, packet, proof ledger, command evidence, side-effect policy, and checkpoint all agree.

The default fallback is always the filesystem protocol. Native subagents, CLI dispatch, and MCP hosts can improve ergonomics, but the project must remain understandable from files on disk.
