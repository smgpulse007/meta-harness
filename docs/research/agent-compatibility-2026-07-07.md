# Agent Compatibility Research - 2026-07-07

This Phase 0 research refreshes public compatibility claims for Meta Harness. It is a claims audit, not native dispatcher enablement. Native dispatch remains disabled for every non-filesystem/fake adapter until local command evidence exists.

## Method

- Refreshed official product documentation for Codex, Claude Code, Cursor, Gemini CLI, GitHub Copilot, Windsurf / Devin Desktop Cascade, Continue, Aider, OpenCode, Roo Code, MCP, Agent Skills, Azure Foundry Agent Service, Azure MCP Server, and context-budget research.
- Ran `pnpm run ci`, which exited 0 before edits.
- Inspected current local adapter and instruction-emitter code.
- Used proof statuses from the Meta Harness protocol: `claimed`, `parent_verified`, `static_verified`, `command_verified`, `runtime_verified`, `human_verified`, `not_verified`, and `partial`.

## Cross-Agent Findings

1. **MCP is the safest shared portability layer.** MCP defines stdio and Streamable HTTP transports; hosts add their own configuration formats and policy controls. Meta Harness should keep a small read-first MCP surface and layer native dispatch only where local evidence exists.
2. **Instruction support is not native automation.** `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.cursor/rules/*.mdc`, `.github/*instructions*.md`, `.windsurf/rules`, `.continue/rules`, `opencode.json`, and `.roo` files can steer hosts, but they do not prove Meta Harness can launch or collect structured packets from those hosts.
3. **Skills favor progressive disclosure.** The Agent Skills specification, Codex, Claude Code, Cursor, and Cascade all point toward small skill metadata plus on-demand body/resources. This supports the Track D budget model.
4. **Headless CLIs exist, but must be locally proven.** Codex, Claude Code, Cursor, Gemini CLI, and Aider document noninteractive/scriptable flows. Meta Harness must not claim native dispatch until it captures command, exit-code, structured-output, token/cost metadata where available, and packet handoff evidence locally.
5. **Cloud and enterprise hosts add policy boundaries.** Copilot cloud agent, Azure Foundry Agent Service, and remote MCP endpoints should be modeled as task/client scenarios with explicit auth, approval, allowlists, audit logs, and read-only defaults.

## Local Support Audit

Local inspection found:

- `packages/adapters/src/index.ts` registers `filesystem`, `fake`, `codex`, `claude-code`, `cursor`, `gemini`, `copilot`, `windsurf`, `aider`, and `opencode`.
- `packages/adapters/src/filesystem.ts` writes prompt files and collects packet files; it does not launch external agents.
- `packages/adapters/src/fake.ts` writes simulated packets and explicitly labels command output as simulation.
- `packages/adapters/src/cli-adapter.ts` detects configured commands but returns `status: "skipped"` for dispatch because automatic process launch is disabled.
- `packages/cli/src/commands/emit-instructions.ts` emits `AGENTS`, `CLAUDE`, `GEMINI`, `CURSOR`, `WINDSURF`, `COPILOT`, `COPILOT_CUSTOM`, `CONTINUE`, `OPENCODE`, and `ROO`; `all` emits 12 files because OpenCode and Roo include config files.
- `.cursor/rules/meta-harness.mdc` has valid-looking `.mdc` frontmatter.
- `.github/instructions/meta-harness.instructions.md` includes `applyTo: "**"` frontmatter.
- `.agents/skills/meta-harness/SKILL.md` and `.claude/skills/meta-harness/SKILL.md` provide host-specific skill placements.
- `docs/examples/mcp-configs/` contains docs-only MCP config samples for Codex, Claude Code, Cursor, Gemini CLI, GitHub Copilot, Windsurf/Cascade, Continue, OpenCode, and Roo.
- `packages/cli/src/commands/context-pack.ts` generates bounded target-specific packs for host handoff, with native dispatch still unverified.

## Claims To Preserve

- Filesystem and fake are the only complete Tier 0 adapters.
- Fake evidence is simulation evidence and must not satisfy production release proof by itself.
- Codex support is partial and conservative today: detection, MCP/write-scope hints, and prompt fallback only.
- Native dispatch for Codex, Claude Code, Cursor, Gemini CLI, Copilot, Windsurf, Aider, and OpenCode is `not_verified`.
- Roo Code is an instruction/MCP compatibility lane, not a current adapter.
- Azure work is documentation/design only until explicit policy authorization exists to create or mutate cloud resources.

## Context-Budget Evidence

The context-budget track is justified by:

- Lost-in-the-middle research: https://arxiv.org/abs/2307.03172
- Context-rot research: https://www.trychroma.com/research/context-rot
- Agent Skills progressive disclosure: https://agentskills.io/specification
- Codex and Cursor subagent guidance that uses parallel agents for read-heavy, context-heavy work.

The practical design implication is to pass bounded context packs, source paths, hashes, short excerpts, and validation commands instead of dumping raw logs or full checkpoint history into every agent prompt.
