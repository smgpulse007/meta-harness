# Parent Coordinator Flow

1. Read the authoritative spec and directional alignment.
2. Read or create the phase manifest.
3. Compile or review the requirement ledger.
4. Build and lint the slice plan.
5. Dispatch ready slices.
6. Collect packets.
7. Verify write scopes, proof, validation, and safety.
8. Write checkpoint artifacts.
9. Decide continuation from `next_action.yaml`.
